# 납품 안내

이번 작업으로 바뀐 것과, 적용할 때 꼭 해야 할 일을 정리했어요.

## 1. 적용하기

레포 폴더에서 패치를 적용하고 GitHub에 올리면 GitHub Pages에 자동으로 반영돼요.

```bash
git am all-in-one.mbox
git push
```

센터 태블릿은 예전 화면을 기억하고 있을 수 있으니 한 번 새로고침해 주세요.

## 2. Firebase 보안 규칙 (꼭 확인)

이번에 새 컬렉션 두 개가 생겼어요.

| 컬렉션 | 용도 |
|---|---|
| `classes` | 반(정기 수업): 요일·시간·정원·명단 |
| `memberLinks` | 회원 전용 링크 값 → 회원 이름 |

보안 규칙이 컬렉션을 하나씩 허용하는 방식이면, 위 두 개도 관리자만 읽고 쓰게 추가해 주세요.
규칙이 "관리자 계정이면 모든 문서 허용" 방식이면 따로 할 일은 없어요.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isAdmin() {
      return request.auth != null
        && request.auth.token.email == 'rlaehgus114@gmail.com'
        && request.auth.token.email_verified == true;
    }
    match /{document=**} {
      allow read, write: if isAdmin();
    }
  }
}
```

규칙이 빠져 있어도 앱은 멈추지 않아요. 시간표·반 관리 화면에 "반·자동 예약을 불러오지 못했어요" 안내가 뜨고, 출석·회원·기록은 그대로 쓸 수 있어요.

## 3. 회원용 화면 켜기 (선택)

회원이 자기 남은 횟수·다음 수업·최근 출석·숙제를 보는 화면(`me/`)이에요. 아래를 한 번만 하면 돼요.

1. https://script.google.com 에서 새 프로젝트를 만들어요. Firebase 프로젝트 소유자 구글 계정으로 해 주세요.
2. `apps-script/member-view.gs` 내용을 `코드.gs`에 붙여 넣어요.
3. 프로젝트 설정에서 "appsscript.json 표시"를 켜고, `apps-script/appsscript.json` 내용으로 바꿔요.
4. 배포 → 새 배포 → 웹 앱, 실행: 나, 액세스: 모든 사용자 → 배포. 권한 허용 창이 뜨면 허용해요.
5. 나온 웹 앱 주소를 `me/index.html`의 `const API = '';` 따옴표 안에 넣고 올려요.
6. 관리자 앱 → 회원 → 이름 → **회원 링크**에서 링크를 복사해 회원에게 카톡으로 보내요.

링크는 회원마다 따로 만들어지고 추측할 수 없어요. 다른 사람에게 갔다면 같은 화면에서 "새 링크로 바꾸기"를 누르면 예전 링크는 바로 안 열려요.

## 4. 알림톡 스크립트와의 관계

- 반 명단으로 만든 자동 예약도 `bookings`에 예전과 같은 모양으로 들어가요(`date`, `time`, `passId`, `name`, `cls`, `slot`, `notified`).
  추가로 `auto: true`, `classId` 필드가 붙어요. 알림톡 스크립트가 이 두 필드를 쓰지 않으면 영향이 없어요.
- 수업 전에 "결석"으로 바꾸면 그날 예약 문서를 지워요. 그래서 알림톡이 안 가요.
- 자동 예약은 **관리자 앱을 열 때** 4주 앞까지 채워요. 4주 넘게 앱을 안 열면 예약이 끊기니 주에 한 번은 열어 주세요.

## 5. 지난 기록에 남은 개인정보

예전 코드에 들어 있던 회원 이름과 금액권 잔액(`MONEY_INIT`)은 이번에 지웠어요.
다만 공개 레포의 **커밋 기록**에는 남아 있어요. 완전히 지우려면 레포를 비공개로 바꾸거나 기록을 정리해야 해요.
